Источник задачи: читатель спросил «что лучше — продолжать учиться или после девятого класса идти работать», и привёл два распространённых тезиса — «некоторые без образования стали боссами», «некоторые из 985-й подрабатывают курьерами».

Охват существующего: по всей книге только пункт 1 раздела 23 (мировая доходность образования 9%) касается темы, при этом он прямо говорит «это не цифра по Китаю, можно использовать только как порядок величины». Поиск по «детский труд», «обязательное образование», «стипендия», «образовательный кредит», «среднее профессиональное», «закон о профессиональном образовании» в book/ — ноль совпадений; «ошибка выжившего» — один раз в примечании к пункту 6 раздела 23, и то про зарплату по данным платформ вакансий, не про уровень образования.
