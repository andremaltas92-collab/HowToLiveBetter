# Запись верификации: раздел 13, дополнение — 9 пунктов (неотложная помощь и野外)

Дата верификации: 2026-09-07. В этом раунде раздел 13 пополнен с 18 до 27 пунктов, всего по книге — с 309 до 318.

Добавлены ранее пропущенные частые смертельные сценарии: анафилактический шок, эпилептический приступ, гипогликемия, поражение электрическим током, отравление угарным газом; а в野外-часть, где раньше были только заблудиться, переохлаждение, укус змеи, встреча с диким зверем, тепловой удар, добавлены грозовой разряд, высотная болезнь, клещ,野外-вода.

Метод аналогичен предыдущим раундам: англоязычные публикации проверяются через Europe PMC REST (`search?query=TITLE:"…"&resultType=core`) для получения библиографической записи и оригинала аннотации; открытые материалы — через `/{PMCID}/fullTextXML` для дословного сверки; страницы официальных органов — через WebFetch с цитированием.

## III. Параметры «жертва / выгода»

Из девяти пунктов семь относятся к смертности (включая жёсткие конечные точки здоровья). Размер выгоды определяется по общему для раздела 13 правилу: непосредственно определяющие выживание (анафилактический шок, тяжёлая гипогликемия, поражение электрическим током, отравление угарным газом, удар молнии, высотный отёк мозга / лёгких) — «большая»; преимущественно избежание вторичного вреда или задержки помощи (эпилептический приступ, клещ,野外-вода) — «средняя». За исключением клеща (нужны пинцет с тонкими кончиками, деньги = мало) все имеют нулевую стоимость; грозовой разряд и высотная болезнь дополнительно отмечены «усилие = да» — сложно не то что знать, а в момент грозы развернуться и не лезть выше на плато.
